## Declaración de uso de IA
Utilicé IA principalmente para organizar las actividades porque la variedad de plataformas y formatos de esta entrega me resultó difícil de asimilar al principio. Particularmente le pedí que proponga un orden específico y si bien resultó de mucha utilidad, en la práctica preferí hacer ciertas cosas de otra forma (por ejemplo decidí primero hacer el tablero y después las historias de usuario, al contrario de lo propuesto). Para el diagrama BPMN primero hice una versión inicial que decidí compartir con el modelo, y si bien seguía las reglas de modelado correctamente, me sugirió agregar un par de elementos como emitir comprobante o enviar un pedido al proveedor a un pool separado, que inicialmente no estaban y deberían estar. Para la sección de indicadores de control y estándares de desempeño la IA resultó particularmente útil ya que si bien esta información en parte estaba incluida en las entregas anteriores, al ser principiante me resulta difícil imaginar qué tipo de indicadores y estándares y mediciones se utilizan normalmente en la industria, por lo que el modelo fue realmente útil para ayudar a conectar los elementos entre sí. En cuanto a github y la tabla interactiva, ya que tengo un poco de experiencia previa, la asistencia fue mínima.
